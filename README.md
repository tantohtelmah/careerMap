# CareerMap

CareerMap is a backend-focused job tracking and notification web application designed to help job seekers — especially students and new graduates — efficiently manage hundreds of job applications across multiple platforms and track a good career path.  

The project highlights backend development, data extraction, automation, and system integration skills.

---

## 📌 Project Scope

CareerMap provides a centralized way to:
- Scrape or manually enter job applications.
- Track application statuses (applied, interview, offer, rejected, etc.).
- Receive follow-up reminders and notifications.
- Organize and filter job applications efficiently.
- Demonstrate backend engineering practices (REST APIs, system design, testing).

This project focuses on **backend architecture and automation**, with a minimal frontend for demonstration purposes.

---

## 🎯 Project Goals

### Backend Development
- Design and implement RESTful APIs.
- Integrate authentication and authorization (JWT/Firebase Auth).
- Schedule background jobs (follow-up reminders).

### Data Extraction & Parsing
- Real-time job scraping using Puppeteer/Playwright/BeautifulSoup.
- Manual entry fallback for custom applications.
- Handle errors gracefully and ensure scraping reliability.

### Testing & Documentation
- Write unit and integration tests.
- Provide clear API documentation (Swagger/OpenAPI).
- Maintain clean, modular, and scalable code.

### Software Design
- Build a developer-centric architecture for backend learning.
- Ensure modular, testable, and reusable components.
- Apply clean code principles and database normalization.

### Project Management
- Break work into **milestones** aligned with backend features.
- Track deliverables in GitHub issues/boards.
- Document technical decisions and learning outcomes.

---

## ⚙️ Core Features (MVP)

1. **Job Entry (Auto & Manual)**
   - Scrape job details from URLs.
   - Allow manual input as fallback.

2. **Job Tracker Dashboard**
   - API endpoints to view, filter, and sort job applications.

3. **Follow-up Notifications**
   - Automated reminders based on application age/status.

4. **Status Updates & History**
   - Track application progression with timestamps.

---

## 🚀 Optional Features (Phase 2)

- Resume attachment support.  
- Tagging and categorization of job applications.  
- Insights and analytics for job search strategy.  

---

## 🛠️ Tech Stack

- **Frontend:** React (minimal), Bootstrap CSS  
- **Backend:** Python (FastAPI)  
- **Database:** PostgreSQL (primary), MongoDB (optional)  
- **Web Scraping:** Puppeteer / Playwright / BeautifulSoup  
- **Notifications:** Cron jobs + SendGrid/Nodemailer  
- **Authentication:** JWT / Firebase Auth  
- **Hosting:** Render / Vercel / Railway

## 🔑 Why CareerMap?

Unlike existing job trackers (Huntr.io, TealHQ, LinkedIn Easy Apply), CareerMap:  
- Emphasizes backend customization and automation.  
- Provides developer-focused learning outcomes.  
- Supports both automated scraping and manual entry.  
- Is open-source and extendable.
